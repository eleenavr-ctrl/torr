# DECISIONS.md — Журнал архитектурных решений (ADR)

1. **ADR-001 — Лицензия Slint Royalty-Free:** Выбрана бесплатная коммерчески-дружественная лицензия Slint с отображением бейджа «Made with Slint» в разделе «О программе».
2. **ADR-002 — Единый источник состояния `AppState`:** Модели списков, счётчики фильтров и живая телеметрия вынесены в Slint global `AppState`, что позволяет делить живые данные между `AppWindow`, `DetachedWindow` и `WorkspaceBuilderView`.
3. **ADR-003 — Фасад совместимости в `src/core/storage.rs`:** Чтобы не ломать проверенные модули `src/modules/torrserver/*`, структура `PortablePaths` сохранена как обёртка поверх `AppPaths` (`UserData/`).
4. **ADR-004 — Без Tokio runtime для WebDAV и обновлений:** Использован уже подключённый `reqwest::blocking` (`rustls-tls`) в выделенных потоках ОС, что снижает размер бинарника и сохраняет простую синхронную модель.
5. **ADR-005 — Профилировщик по требованию:** Детальный сбор Working Set / Private Bytes / Handles / GDI / USER включён в Настройках и выключен по умолчанию (мини-CPU/RAM для сайдбара читается легковесно).
