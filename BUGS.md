# BUGS.md — Известные ограничения и история исправлений

## Решённые проблемы
- Потеря добавленных задач при перезапуске локального TorrServer — исправлено сохранением метаданных и восстановлением списка.
- Ошибки `windows-sys` типов `COINIT` / `GetGuiResources` / `HANDLE::is_null` и заимствований в `metadata.rs` — исправлены и подтверждены.
- Разъезд окна при отключении внешнего монитора — добавлена проверка `MonitorFromRect(..., MONITOR_DEFAULTTONULL)` при старте.

## Ограничения среды
- В контейнере веб-редактора отсутствует локальный компилятор Rust (`cargo`), поэтому финальная сборка `.exe` и запуск `cargo test` выполняются в CI GitHub Actions (`.github/workflows/build.yml`).
