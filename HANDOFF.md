# HANDOFF.md — Передача контекста и инструкция по сборке

## 1. Текущее состояние проекта
Проект **TorrServerUI v0.1.0** полностью спроектирован и реализован в составе 31 файла:
- Ядро оболочки (`src/core/*`) с темой Windows 11, треем, Single-Instance Mutex, Win32 Drag-and-Drop и шиной диагностики.
- Реестр модулей (`src/modules/mod.rs`) и первый самодостаточный модуль `torrserver` (`src/modules/torrserver/*`, включая прямой поиск по RuTracker и экспорт/импорт `.json`).
- Полный интерфейс на Slint 1.9 (`fluent`) в `ui/`.
- CI workflow для Windows x64 в `.github/workflows/build.yml`.

## 2. Как собрать `.exe` через GitHub Actions
1. Инициализируйте git-репозиторий и отправьте файлы в ветку `main` на GitHub.
2. Откройте вкладку **Actions** в репозитории GitHub — workflow **Build Windows x64** запустится автоматически (либо нажмите **Run workflow** вручную).
3. После завершения задания скачайте артефакт **`TorrServerUI-windows-x64`**, внутри которого находится готовый портативный **`TorrServerUI.exe`**.
4. Для публикации релизов с прикреплённым `.exe` создайте тег вида `v0.1.0` и отправьте его (`git push origin v0.1.0`).

## 3. Локальная сборка на Windows 10/11
1. Установите Rust toolchain (`x86_64-pc-windows-msvc`) через `rustup`.
2. Выполните в корне проекта:
   ```powershell
   cargo build --release --target x86_64-pc-windows-msvc
   ```
3. Готовый файл: `target\x86_64-pc-windows-msvc\release\torrserver-ui.exe` (переименуйте в `TorrServerUI.exe`).

## 4. Чек-лист проверки первого запуска
- [ ] Положите `TorrServerUI.exe` в отдельную чистую папку (например `D:\Portable\TorrServerUI\`).
- [ ] После запуска убедитесь, что рядом создалась папка `data\`, `data\torrserver\`, `data\modules\`, `data\config.json`.
- [ ] На вкладке «Раздачи» при отсутствии движка появится баннер с кнопкой скачивания — нажмите её и убедитесь, что `TorrServer-windows-amd64.exe` скачался в `data\torrserver\`.
- [ ] Проверьте нижний статус-бар (должен стать зелёным, отображать версию движка и пинг).
- [ ] Нажмите на крестик окна — окно должно скрыться в системный трей, а при клике по иконке трея или повторном запуске `.exe` — развернуться обратно.
- [ ] В Настройках откройте секцию диагностики и проверьте работу кнопок «Проверить сейчас» и «Скопировать для ИИ».
